# 输入文件规范

[English](inputs.en.md) | [操作指南](usage.zh-CN.md) | [仓库首页](../README.md)

## 必须准备的两类文件

| 文件 | 内容与来源 |
|---|---|
| `sample1_R1.fq.gz` | 测序平台提供的、已按样品拆分的单端 reads 及质量值；一次使用一个样品的一个读端 |
| `amplicons.fa` | 自己确认的一个或多个完整目标扩增子序列，保留原始 A；来自原始转录本或构建体设计，不能只写两条引物 |

这些名称都是占位符。每个样品单独运行；相同设计可共用参考。不需要全基因组、GTF、STAR 索引、样品 Excel 表或手工注释文件。

## FASTQ

- 每条 read 为四行：`@名称`、碱基序列、以 `+` 开头的分隔行、质量字符。序列和质量长度必须相同，不能折行；质量编码为 Phred+33。
- 第一个空白之前的 read 名称必须在整份文件中唯一。保留平台原始名称，不用 Word/Excel 编辑 FASTQ。
- 支持 `.fq`、`.fastq`、`.fq.gz`、`.fastq.gz`；gzip 文件必须以小写 `.gz` 结尾。改扩展名不等于压缩或解压。
- 选择与原始 RNA 正向参考一致、适合 A→G 分析的一端；R1 并非所有建库的正确选择。不要合并 R1/R2 或不同样品。同一样品跨 lane 合并时，仍需保证同一读端及 read ID 唯一。
- 指南先去测序接头，再把清洗后的 FASTQ 交给主程序。i5/i7 是样品 index，不是分子 UMI。本直接流程假定没有分子 UMI；若有 UMI/inline barcode，须按真实建库结构预处理。无 UMI 扩增子不要仅凭序列/坐标去重。

## 原始扩增子 FASTA

用纯文本保存，每条记录以 `>扩增子ID` 开头，后面填写自己的实际完整序列；序列可规范折行。仓库不提供占位碱基或示例数据。

| 项目 | 要求 |
|---|---|
| 格式 | 未压缩 `.fa` / `.fasta`；参考脚本不直接读 `.fa.gz` |
| 方向与来源 | 原始 RNA 的 5′→3′方向，使用对应转录本/剪接形式或实际构建体；不是转换后 reads 的共识 |
| 碱基 | `A/C/G/T/N`，U 写成 T；每条至少一个原始 A，不提前 A→G；建议大写 |
| ID | 唯一、简短；首字符为英文字母/数字，其余限英文字母、数字、`_ . -`；不含空格或 `_AG_converted` |
| 范围 | 与去测序接头后待比对的目标片段一致，不含测序 adapter、i5/i7 index 或无关载体序列 |
| 权限 | 参考所在目录可写，程序会在旁边创建 `.fai` |

`N` 不是可定量的 A，且可能降低比对覆盖，应尽量确认实际碱基。不要把含内含子的基因组片段直接用作成熟 RNA 参考。

测序接头与 PCR 引物不同：标准接头清洗不会自动识别基因特异性引物。参考和 reads 的处理必须一致，不能只删参考两端却保留 reads 对应部分。定量位点应避开 PCR 引物直接写入碱基的区域，本程序不会自动屏蔽。

多个扩增子 A→G 后若相同或高度相似，唯一比对规则可能排除相应 reads；换 ID 不能消除序列歧义。

## 需要核对的信息与自动生成文件

依据实验记录确认样品、读端方向、接头类型、UMI 状态、扩增子/引物边界及对照和重复。目标位点按原始 FASTA 从 1 开始计数；无需额外提交引物文件或 BED 位点表。

| 生成文件 | 来源/用途 |
|---|---|
| 清洗后的 `.fq` | Trim Galore 生成，交给主程序 `-q` |
| `panel.AG_conversion.fa` | 参考准备脚本生成，交给 `-f` |
| 六个 `.ebwt` 和两份 `.fai` | 自动生成的 Bowtie1 / FASTA 索引 |
| `panel.baseanno` | 自动生成的位点注释，交给 `-b` |
| BAM、转化率和位点表 | 主程序的输出 |

`-f2` 使用原始未转换 FASTA，不与 `-f` 互换。修改参考或 ID 后须重新建全部索引。

## 运行前检查

激活环境、替换路径后执行：

```bash
ls -lh /path/to/your/data/sample1_R1.fq.gz /path/to/your/data/amplicons.fa
gzip -t /path/to/your/data/sample1_R1.fq.gz
seqkit stats /path/to/your/data/sample1_R1.fq.gz /path/to/your/data/amplicons.fa
cat /path/to/your/data/amplicons.fa
```

依次检查文件存在/大小、压缩完整性、条数/长度、实际参考内容。文件应非空；`gzip -t` 成功时无输出，未压缩 FASTQ 跳过它。这些检查不能代替实验设计核对。随后按[操作指南](usage.zh-CN.md)运行。
